# Analytics Module Reference — `analytics/`

Moved out of CLAUDE.md on 2026-08-04 to cut the auto-loaded context floor
(~28k -> ~5k tokens per session). **CLAUDE.md keeps the package index and the
verdicts; this file holds the detail.** If a package's PURPOSE or VERDICT changes,
update CLAUDE.md too — the index is the only path a session has to this file.

**Rebuilt 2026-08-04.** The previous version of this file described the PRE-Phase-2
layout (`data_store.py` / `signal_lib.py` / `stats_lib.py` / `backtest_lib.py` as
primary modules — all four are re-export shims today) and had zero coverage of
`brief/`, `forecast/`, `xsmom/`, `carry/` or `combine/`. It was retired rather than
merged, because merging a pre-split map into a current one produces contradictions.

- `audit_guard.py` — P0a-2 commit gate (sub-PR 2): `evaluate_audit_cells(cells, *, bar=0.05, alpha=0.05, min_n=30, ...)` → list of `CellVerdict` (`ENABLE` / `DISABLE` / `CONCENTRATE` / `INSUFFICIENT`). Replaces the audit tools' crude ±0.05R bar with two gates that BOTH must hold: a serial-correlation-aware **bootstrap CI** (`block_bootstrap_ci`) on the suppressed slice's mean R clearing the ±bar, AND a **Holm multiple-testing-adjusted p-value** (`haircut_sharpe` over the tested-cell family) < alpha. Below-`min_n` cells are `INSUFFICIENT` and excluded from the haircut family. Pure (consumes `research_guards`, no DB/IO); mirrors `sweep_guard.py`'s verdict shape. - `structural_entry_sim.py` — faithful per-strategy structural entry-simulation harness (pure, read-only; the pre-committed escalation from `structural_touch.py`'s DECAY-CONFIRMED touch-decay verdict; verdict `docs/audits/2026-06-26-structural-entry-sim-harness.md`). Converts the gross-of-cost first-touch excursion premium into **cost-netted realized avg_r**: each indexed touch → one synthetic engine signal (`build_touch_signals` with a structural far-edge `sl_price` via `touch_sl_price`'s `structural`/`atr_floor`/`fixed_atr` models), resolved through the production `run_backtest` for ZERO cost/SL/TP drift — the sl-model is computed here and `min_sl_pct=0`/`atr_sl_floor=False` are passed so `Trade.sl_price` is unmodified and the `(open_time, direction, sl_price)` touch↔trade merge (`_merge_touches_to_trades`) is exact (identical key ⇒ identical deterministic trade), then tagged back to `touch_index`. `extract_zone_touches` (zones extracted once per (symbol, tf, zone_type), reused across the tp_r×sl_model grid), `simulate_cell`, `build_realized_table`, and the pre-committed `evaluate_build` BUILD/NO-EDGE/INSUFFICIENT gate (decision keyed on a fixed headline config + boot-CI>0 + Holm over the cell family + n≥MinTRL + DSR/PBO over the tp_r×sl_model family; first−repeat decay lift secondary). Consumed by `tools/structural_entry_sim_audit.py`.
- `sl_horizon.py` — ST9/H11 SL-horizon audit, pure library (spec `docs/superpowers/specs/2026-07-21-st9-sl-horizon-audit-design.md`). Six candle detectors (`doji`/`engulfing`/`hammer_hanging_man`/`inside_bar`/`morning_evening_star`/`pin_bar`) hard-code `sl_pct=0.02` at every timeframe; this re-resolves the same signals under an a-priori `k × ATR14` grid (`k in (0.5, 1.0, 1.5, 2.0, 3.0)`, `tp_r` pinned from the live config, never swept) to test whether the family's graveyard verdict is an artifact of a dimensionally wrong stop. `SLGridConfig` (frozen, fee/slippage/bar/alpha/min_n a-priori), `baseline_levels`/`counterfactual_levels` (the flat-2% vs `k×ATR` arms), `atr_by_open_time` (delegates to the engine's `_compute_atr14` — audit and live path cannot disagree on ATR), `window_for_signal` (two entry conventions, `"engine"` vs `"live"` — the difference is load-bearing for the fidelity check), `resolve_arm` (nets `realized_r − cost_r − funding_r` via `exits.replay`), `build_paired_table`/`describe_horizon`, and the pre-committed `evaluate_sl_grid` SUSPECT/CONFIRMED-BAD/NO-DIFFERENCE/INSUFFICIENT verdict (paired per-signal lift fed to `audit_guard.evaluate_audit_cells` + DSR/PBO over the k-grid family). Consumed by `tools/sl_horizon_audit.py` (`make buibui-sl-horizon-audit`).
- `weekly_path.py` — H10 partial-path predictiveness audit, pure library (spec `docs/superpowers/specs/2026-07-23-h10-partial-path-predictiveness-design.md`). Tests whether the week's AWR-normalized path at hour `h` predicts the return from `h` to the week's close, **beyond drift** — the non-tautological version of the cone's conditional-on-outcome framing. Signs the **causally demeaned** remaining return (expanding mean over strictly earlier weeks) and collapses the cross-section to **one observation per calendar week**, since 6,000 symbol-weeks are nowhere near independent. Pre-committed gate at `h ∈ {24,48,72,96,120}`, `bar = 0.05` AWR, Holm over the 5-hour family, plus an early/late sign-agreement condition. **Note:** `audit_guard`'s decisions are inverted relative to the sign of the mean (`DISABLE` ⇔ reliably positive), so `DISABLE → PREDICTIVE` and `ENABLE → REVERTING`. Consumed by `tools/weekly_path_audit.py`.
- `indicator_condition.py` — H8 M1 indicator-state conditioning audit, pure library (spec `docs/superpowers/specs/2026-07-24-h8-m1-indicator-conditioning-design.md`; verdict `docs/audits/2026-07-24-h8-m1-indicator-conditioning.md`). Tags each historical trade with the M1 brief-indicator state as-of its entry (`build_indicator_state` over the causal 1d+1h slice, memoized by `(symbol, entry_time)`; look-ahead mutation-guarded) and emits a pre-committed BUILD / AVOID / NO-EDGE / INSUFFICIENT verdict per `(axis-state × direction)`. `IndicatorConditionConfig`, `axis_states` (the 10 pre-registered axes: ema_stack/ema_slope/regime/bb_squeeze/bb_pctb/vwap_weekly/vwap_monthly/vp_value_area/pa_char/monday_range), `tag_trades`, `build_condition_cells` (the "without" slice = same-direction trades whose value on that axis differs), `evaluate_conditions` (one Holm family across all cells via `audit_guard` + a two-sample with-vs-without lift CI + per-`(axis, direction)` DSR/PBO stamp + the spec §7 MinTRL(0.95) leg) and the **sign-inverted** `_map_verdict` (`DISABLE → BUILD`, `ENABLE → AVOID` — the same audit_guard inversion that bit ST9). **`_family_dsr` and the MinTRL call both fold the Sharpe to its MAGNITUDE on purpose:** `deflated_sharpe_ratio` of a raw negative Sharpe is ~0 and `min_track_record_length` of one is `inf`, so the signed form made the AVOID verdict structurally unreachable (PR #546). Do not "simplify" the `abs()` away. **Verdict: the published 2026-07-24 NO is UNDER RE-EXAMINATION** — it was produced by a build in which AVOID could essentially never fire and the pre-committed MinTRL leg was absent; the re-run surfaces 25 AVOID cells, 17 of them long-side, where the published table had none. Read the original's BUILD findings as still standing and its "every gate-grade cell is short-side" conclusion as suspect until the amendment lands. Consumed by `tools/indicator_condition_audit.py`.
- `reference_levels.py` — calendar reference-level geometry (look-ahead-safe), pure sibling to `zones_lib.py`: `compute_levels` / `compute_levels_table` (vectorized per-day table) / `nearest_level` / `sweep_flag`.
